# Atualizar o projeto para Go 1.27.3 — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Atualizar a versão mínima e as ferramentas de CI do Bearm para Go 1.27.3, a versão estável mais recente verificada em 2026-11-02.

**Architecture:** Alterar o `go` directive dos módulos do produto e de ferramentas e alinhar o workflow de readiness, que hoje fixa Go 1.26.1. Preservar a matriz CI de versão mínima exata `1.27.3` e `stable`, que passará a testar Go 1.27.3 quando essa for a versão estável. Atualizar documentação que declara a versão mínima; validar dependências, build, testes e workflows nos sistemas suportados.

**Tech Stack:** Go modules, GitHub Actions, Go 1.27.3, Linux e macOS.

**Spec:** Este plano define o escopo; a versão 1.27.3 foi verificada na página oficial de downloads: https://go.dev/dl/.

## Global Constraints

- Go 1.27.3 é a versão mínima e alvo desta atualização.
- Linux e macOS continuam suportados em `amd64` e `arm64`.
- Não atualizar dependências de aplicação sem necessidade demonstrada por build ou testes.
- Preservar verificações atuais de CI, release e readiness.

## Review Focus

- Ferramentas no CI realmente usam Go 1.27.3, não apenas uma variável `stable` num job isolado.
- `go.mod` e, se atualizado pelo Go, `go.sum` permanecem válidos sem upgrades não relacionados.
- Todos os testes e builds passam em Linux e macOS; syscall/build tags continuam corretas.
- Documentação inglesa e portuguesa anunciam o mesmo mínimo suportado.
- Release/readiness e comandos de desenvolvimento local continuam coerentes com o novo mínimo.

## Task 1: Atualizar a versão do módulo

**Files:**
- Modify: `go.mod`
- Modify: `tools/go.mod`
- Modify if required: `go.sum`
- Modify if required: `tools/go.sum`

**Interfaces:**
- Consumes: dependências e pacote atuais.
- Produces: os módulos do produto e de ferramentas declarando Go 1.27.3.

- [ ] **Step 1: Registrar o comportamento de baseline.** Executar `go mod tidy -diff` (raiz e `tools/`) e `go test ./...` com Go 1.27.3 antes de editar; guardar falhas preexistentes separadas das falhas de compatibilidade.
- [ ] **Step 2: Atualizar os directives de `go.mod` e `tools/go.mod` para `go 1.27.3`.** Não adicionar `toolchain` directive sem evidência de que o projeto precisa fixar compilador além do mínimo.
- [ ] **Step 3: Validar metadados do módulo.** Executar `go mod tidy -diff` (raiz e `tools/`) e `go mod verify` (raiz e `tools/`); se `tidy -diff` apontar apenas agrupamento preexistente de `require`, normalizar sem alterar versões; atualizar sum files só se necessário.
- [ ] **Step 4: Validar build e testes Linux.** Executar `go test ./...`, `go test -race ./...` e `go vet ./...` com Go 1.27.3; todos devem passar.

## Aceitação e limites

O plano só está concluído quando `go.mod`, CI, readiness e documentação apontarem para Go 1.27.3+, os gates Linux e macOS estiverem verdes e o diff não contiver upgrades de dependência sem relação com a migração. Nenhuma atualização foi implementada ao escrever este plano.
